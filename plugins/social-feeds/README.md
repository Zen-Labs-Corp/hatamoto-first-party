# social-feeds

Shows your latest Instagram posts and YouTube videos from a copy refreshed every few hours, as page-builder data sources.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/social-feeds`.
