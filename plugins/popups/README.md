# popups

Announcement bars and popups with page targeting, start and end dates and frequency caps, built to stay accessible and keep pages cached.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/popups`.
