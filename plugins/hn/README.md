# hn

A Hacker News style community: stories, votes, karma, ranked threads, flags and moderation on top of Hatamoto's core comments.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/hn`.
