# reviews

Shows your Google and Trustpilot reviews on your pages from a copy refreshed daily, as a page-builder data source and a ready-made section.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/reviews`.
