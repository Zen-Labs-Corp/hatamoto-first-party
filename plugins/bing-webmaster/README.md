# bing-webmaster

Bing Webmaster Tools: submit your sitemap and see Bing clicks, impressions, top queries and crawl issues, using your Bing API key.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/bing-webmaster`.
