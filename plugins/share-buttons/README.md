# share-buttons

Share links for posts and pages (LinkedIn, X, Facebook, WhatsApp, Bluesky, email) as a partial and a section, with no tracking scripts.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/share-buttons`.
