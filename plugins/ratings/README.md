# ratings

Star ratings for posts and pages: visitors rate with a plain form, the average shows on the page and you see totals per page.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/ratings`.
