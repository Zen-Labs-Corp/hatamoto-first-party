# appointments

Booking from Cal.com or Calendly: an embedded scheduler section and a booking button that use your scheduling link.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/appointments`.
