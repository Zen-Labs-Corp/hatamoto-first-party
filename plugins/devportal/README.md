# devportal

Developer accounts for hatamoto.dev: sign in with GitHub, accept the terms, register one signing key.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/devportal`.
