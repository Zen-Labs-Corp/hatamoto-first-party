# payment-links

Take payments and donations through Stripe Payment Links: payment buttons for your pages, an owner email per payment and a payments log.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/payment-links`.
