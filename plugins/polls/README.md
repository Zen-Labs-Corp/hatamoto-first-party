# polls

Turns Hatamoto forms into polls, surveys and scored quizzes, with live results, per-question breakdowns and CSV export.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/polls`.
