# link-checker

Finds broken outbound and internal links in your published content on a schedule and lists each one with the page it is on and a link to fix it.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/link-checker`.
