# uptime-monitor

Checks your site and other web addresses every few minutes, emails you when one goes down or comes back, warns before an SSL certificate expires and can ping an outside heartbeat.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/uptime-monitor`.
