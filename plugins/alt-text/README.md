# alt-text

Suggests alt text for images in your media library that have none, using a vision model you choose, and stages each one for your review.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/alt-text`.
