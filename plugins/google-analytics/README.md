# google-analytics

Google Analytics: adds the Google tag (gtag.js) for your GA4 measurement ID to every public page, with a way to leave your own visits out.

## Use

1. Install the plugin from Admin > Settings > Plugins.
2. Grant the permissions it asks for.
3. Open its **Settings** tab.

## Permissions

- `settings`: reads its own settings.

## Build

From the repository root: `scripts/build-plugin.sh plugins/google-analytics`.
